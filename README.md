# Maqueta de la tienda de cadenas

Página de ejemplo para ver cómo podría verse la tienda. No vende nada: el nombre, los precios, los textos y las imágenes son de ejemplo.

- El nombre de la marca es `NOMBRE` (a definir).
- Los textos marcados "a confirmar" dependen de lo que confirme el proveedor por escrito.
- Las cadenas son ilustraciones dibujadas con código, no fotos reales.
- La página tiene `noindex`, así que los buscadores no deberían listarla.
